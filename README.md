# Aprendizagem de Máquina e vida 🧠

Este repositório foi criado para armazenar os projetos, códigos e atividades desenvolvidos durante a disciplina de **Aprendizado de Máquina e vida**, cursada no **Instituto do Cérebro (ICe)**.

O objetivo do repositório é registrar o progresso prático nos estudos de algoritmos de Machine Learning, análises exploratórias de dados e modelagens preditivas aplicadas ao longo do período.
